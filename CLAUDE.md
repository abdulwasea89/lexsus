# Lexsus project instructions

Read and follow [AGENTS.md](AGENTS.md) before working in this repository.
Follow its startup reading order: `AGENTS.md`, `lexsus.md`,
`ENGINEERING_STANDARDS.md`, then `SESSION_CONTEXT.md`.

These files contain the shared repository rules, product requirements,
engineering standards and recorded session context. Inspect the current
working tree and applicable nested instructions before editing. Update
`SESSION_CONTEXT.md` before ending a work session; keep durable rules in
`AGENTS.md` rather than duplicating them here.
